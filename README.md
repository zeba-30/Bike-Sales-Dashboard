# Bike Sales Dashboard 🚲📊

An interactive Excel dashboard built to analyze bike purchasing behaviors, customer demographics, and purchasing trends.

## 📌 Project Overview
This project visualizes customer purchasing patterns for bikes based on various demographic and socioeconomic factors. It helps answer key business questions regarding who buys bikes and what influences their purchasing decisions.

## 🎛️ Dashboard Features & Slicers
The dashboard includes interactive filters (slicers) to dynamically explore the data by:
* **Marital Status:** Married vs. Single customers.
* **Region:** Europe, North America, and Pacific markets.
* **Education Level:** Bachelors, Graduate Degree, High School, Partial College, and Partial High School.

## 📈 Key Insights Visualized
* **Avg Income Per Purchase:** Compares average income levels between male and female customers who did or did not purchase a bike.
* **Customer Age Brackets:** Analyzes purchase trends across Adolescent, Middle Age, and Old age groups.
* **Customer Commute:** Evaluates how commute distance (ranging from 0-1 miles to over 10 miles) affects bike purchasing decisions.

## 🛠️ Tools & Skills Used
* **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, and Dashboard Layout Design.
* **Data Analysis:** Exploratory Data Analysis (EDA) and business metrics visualization.
