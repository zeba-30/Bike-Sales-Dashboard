# Bike Sales Dashboard 🚲📊

An interactive Excel dashboard built to analyze bike purchasing behaviors, customer demographics, and purchasing trends.

## 📌 Project Overview
This project visualizes customer purchasing patterns for bikes based on various demographic and socioeconomic factors[span_1](start_span)[span_1](end_span). It helps answer key business questions regarding who buys bikes and what influences their purchasing decisions.

## 🎛️ Dashboard Features & Slicers
The dashboard includes interactive filters (slicers) to dynamically explore the data by:
* **Marital Status:** Married vs. Single customers[span_2](start_span)[span_2](end_span)
* **Region:** Europe, North America, and Pacific markets[span_3](start_span)[span_3](end_span)
* **Education Level:** Bachelors, Graduate Degree, High School, Partial College, and Partial High School[span_4](start_span)[span_4](end_span)

## 📈 Key Insights Visualized
* **Avg Income Per Purchase:** Compares average income levels between male and female customers who did or did not purchase a bike[span_5](start_span)[span_5](end_span).
* **Customer Age Brackets:** Analyzes purchase trends across Adolescent, Middle Age, and Old age groups[span_6](start_span)[span_6](end_span).
* **Customer Commute:** Evaluates how commute distance (ranging from 0-1 miles to over 10 miles) affects bike purchasing decisions[span_7](start_span)[span_7](end_span).

## 🛠️ Tools & Skills Used
* **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, and Dashboard Layout Design[span_8](start_span)[span_8](end_span).
* **Data Analysis:** Exploratory Data Analysis (EDA) and business metrics visualization.
